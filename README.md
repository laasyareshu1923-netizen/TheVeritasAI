# The Veritas AI

An enterprise-grade **Streamlit application** engineered to systematically classify real vs. fake streams using simulated **Deep Learning** text classifiers combined with interactive **Reinforcement Learning (Contextual Bandit)** adaptive tracking loops.

## ✨ Features
- **Integrated Verification Desk:** Structured framework processing text arrays and news categories.
- **Sourcing Infrastructure:** Synthesizes national coverage networks alongside dedicated local metro selectors for **Visakhapatnam (Vizag)** and other key regional hubs.
- **Fail-Safe Crash Protection:** Built entirely using functional abstractions, immutable cached states (`@st.cache_data`), and isolated dependencies to guarantee zero runtime crashes.

## 🚀 Step-by-Step Local Deployment
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Run the application:
   ```bash
   streamlit run app.py
   ```
